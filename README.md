# JoomEngine

JoomEngine brings [JoomEngine Playground](https://playground.joomengine.org/) to your desktop. Build Joomla extensions with Joomla Component Builder, keep your workspace between sessions, and export a complete site.

**[Download JoomEngine](https://github.com/joomengine/joomengine/releases/latest)** · **[Installation guides](docs/README.md)**

Open **Assets** on the release and choose the file for your computer. New package formats appear first in [preview builds](https://github.com/joomengine/joomengine/releases?q=continuous-&expanded=true).

| Your computer | Download and install |
| --- | --- |
| [Windows 10/11 x64](docs/install-windows.md) | Extract the Windows ZIP and open **JoomEngine.exe**, or double-click the publisher-signed MSIX. |
| [macOS](docs/install-macos.md) | Choose the Apple silicon (`arm64`) or Intel (`x64`) DMG. Drag **JoomEngine** into **Applications**. |
| [Debian 13](docs/install-debian.md) | Download the `.deb` and install it with APT. |
| [Arch Linux](docs/install-arch.md) | Download the `.pkg.tar.zst` and install it with pacman. |
| [Fedora 44](docs/install-fedora.md) | Download the `.rpm` and install it with DNF. |
| [Flatpak](docs/install-flatpak.md) | Open the `.flatpak` bundle in your software center and choose **Install**. |
| [Snap](docs/install-snap.md) | Download `joomengine-install-snap.sh` and run `bash ./joomengine-install-snap.sh`. |
| [AppImage](docs/install-appimage.md) | Download the `.AppImage` and run its built-in installer. |
| [Ubuntu 26.04 archive](docs/install-linux-archive.md) | Extract the `-linux-x64.tar.gz` and run `./install.sh`. |

The Linux packages are for Intel and AMD 64-bit desktops. Connect to the internet when you first open Playground.
