# Install JoomEngine on Linux

Choose one installation method for your x86-64 Intel or AMD desktop.

| If you use | Choose |
| --- | --- |
| Debian 13 (Trixie) | [Debian package](install-debian.md) |
| Arch Linux | [Arch package for pacman](install-arch.md) |
| Fedora 44 | [Fedora RPM](install-fedora.md) |
| A system with Flatpak | [Flatpak bundle](install-flatpak.md) |
| Ubuntu or another system with snapd | [Snap installer](install-snap.md) |
| A desktop where you want a portable executable | [AppImage](install-appimage.md) |
| Ubuntu 26.04 with the distribution's Qt runtime | [Native archive](install-linux-archive.md) |

On a derivative distribution, choose Flatpak, Snap or AppImage if the native package's dependencies are unavailable. `uname -m` shows your computer's architecture.
