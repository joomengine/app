# Install the JoomEngine Snap

1. Download **joomengine-install-snap.sh** from the [JoomEngine releases](https://github.com/joomengine/joomengine/releases). This single installer includes the JoomEngine package.
2. From the download folder, run the installer. Enter your administrator password if prompted.

   ```sh
   bash ./joomengine-install-snap.sh
   ```

3. Open **JoomEngine** from the applications menu or run `snap run joomengine`.

To update, quit JoomEngine and run the new installer. This also upgrades an existing 0.1.0 Snap. If you prefer the store, choose **Install** on the [JoomEngine Snap Store page](https://snapcraft.io/joomengine) once the stable listing is public.
