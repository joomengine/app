# Install JoomEngine on Arch Linux

1. On an up-to-date x86-64 Arch system, download the file ending in `-x86_64.pkg.tar.zst` from the [JoomEngine releases](https://github.com/joomengine/joomengine/releases).
2. In the download folder, install the package. Pacman will fetch its dependencies.

   ```sh
   sudo pacman -U ./joomengine-*-x86_64.pkg.tar.zst
   ```

3. Open **JoomEngine** from the applications menu or run `joomengine`.

To update, close the app and repeat the command with the new package.
