# Install the JoomEngine AppImage

1. Download the `.AppImage` from the [JoomEngine releases](https://github.com/joomengine/joomengine/releases).
2. In the download folder, run the built-in installer. It may ask for your administrator password.

   ```sh
   chmod +x ./JoomEngine-*-x86_64.AppImage && ./JoomEngine-*-x86_64.AppImage --appimage-extract-and-run --install
   ```

3. Open **JoomEngine** from the applications menu.

To update, quit the app and run the same installer with the new download.
